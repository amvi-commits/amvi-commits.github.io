# XTM Backup public information

Static homepage and privacy policy for the **XTM Backup** personal backup utility.

This repository contains only public explanatory HTML/CSS. It does **not** contain
the backup application source, backups, account data, databases, OAuth credentials,
recovery keys, environment files, or production configuration.

Hosting: GitHub Pages from the default branch root, using the provided `github.io`
address. No custom domain, paid plan, server, or additional subscription is required.

Google OAuth app publishing and any domain ownership verification are separate
settings. A successful Pages deployment alone is not proof of Google's approval.

Contact: [GitHub Issues](https://github.com/amvi-commits/amvi-commits.github.io/issues).
Please never submit private backup data, credentials, or recovery keys in an issue.
